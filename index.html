Welcome to: FTC Search Shark
A faster, more efficient way to search and understand FTC rules.

FTC Search Shark is built by Team 33574, the Baby Sharks, to help teams quickly find and understand official FTC game manual rules. Each season’s rulebook is large and often difficult to search through during preparation or competition, so we created a tool to make that process faster and more accessible.

Our system allows users to search the FTC manual using keywords and instantly find relevant rules, definitions, and gameplay details. Instead of scrolling through hundreds of pages, teams can simply put in keywords and the Search Shark will find all relevant rules!

This project was built to improve efficiency, reduce confusion during rule interpretation, and help teams focus more on strategy and robot design.
